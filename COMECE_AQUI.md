## 🚀 SEU PRIMEIRO PROJETO (10 MINUTOS)

### Meta: Mudar o título do site

**Passo 1**: Leia `COMECO_RAPIDO.md` (2 min)
**Passo 2**: Abra `index.html` com Bloco de Notas
**Passo 3**: Procure com Ctrl+F: `<title>`
**Passo 4**: Mude o título
**Passo 5**: Salve (Ctrl+S)
**Passo 6**: Recarregue navegador (Ctrl+F5)
**Pronto!** ✅

Demorou 5 minutos? Agora tente mudar uma cor! (2 min mais)

## ⚠️ REGRAS IMPORTANTES

### 🔴 NUNCA faça isso:

```
❌ Delete chaves, parênteses ou aspas
❌ Mude nomes de funções em JavaScript
❌ Mude estrutura interna de funções
❌ Mude espaçamento aleatoriamente
```

### ✅ SEMPRE faça isso:

```
✅ Faça backup antes (Ctrl+C copie o conteúdo)
✅ Procure com Ctrl+F
✅ Mude apenas o conteúdo, não a estrutura
✅ Salve (Ctrl+S)
✅ Recarregue (Ctrl+F5)
✅ Teste no navegador
```

- Guia: `EDITAR_HTML_GUIA_COMPLETO.md`

- Arquivo: `styles.css`
- Guia: `EDITAR_CSS_GUIA_COMPLETO.md`
